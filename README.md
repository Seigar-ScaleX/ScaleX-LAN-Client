# ScaleX LAN Client

Официальные portable-сборки Windows-клиента ScaleX LAN Manager.

Готовые сборки доступны в GitHub Releases. Этот репозиторий предназначен для распространения клиента; исходники сервера менеджера здесь не публикуются.

Скачайте архив с окончанием `portable-win-x64.zip`, распакуйте и запустите корневой `ScaleX.exe`. Для работы нужен ваш сервер ScaleX LAN Manager и Microsoft Edge WebView2 Runtime.

Начиная с 0.3.3 клиент проверяет этот репозиторий при запуске и каждые шесть часов. Ручная проверка — через меню «Обновления». Новая версия устанавливается после подтверждения и проверки незавершённых действий. Подпись манифеста и SHA256 пакета проверяются клиентом.

Папку `portable-data` не удаляйте и не публикуйте: в ней находятся локальные настройки и защищённый Windows ключ устройства. В готовых релизах пользовательских профилей и ключей нет.

Файл `ScaleX-VERSION.zip` предназначен для updater; архив `ScaleX-VERSION-portable-win-x64.zip` — для первой установки.

Компоненты сторонних разработчиков поставляются со своими лицензиями в составе архива. Раздача бинарников не меняет условия этих лицензий.
